# Atividade Django — Back-End

Repositório acadêmico destinado às atividades práticas da disciplina de Back-End, utilizando Python e o framework Django.

## Atividade 6 Extra — Django

A atividade consiste no desenvolvimento de um sistema web simples de **Gestão de Tarefas**, utilizando Django para praticar a criação de projetos e aplicações, configuração de URLs, views e templates.

Nesta etapa, as tarefas são armazenadas temporariamente em memória, sem utilização de banco de dados.

## Conteúdos praticados

- Criação de um projeto Django
- Criação e configuração de uma aplicação
- Configuração de URLs
- Criação de views
- Utilização de templates HTML
- Passagem de dados das views para os templates
- Estruturas condicionais e de repetição com Django Templates
- Execução e testes do servidor de desenvolvimento
